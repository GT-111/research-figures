# research-figures

面向具身智能研究的论文绘图 skill：从项目贡献出发，生成视觉母稿，再重建可编辑架构图、精确结果图与图组。

默认风格是苔绿／麦黄／灰蓝、手写短标签、粗墨轮廓与有节制的阴影、虚线和斜线纹理。科学关系和数值优先于风格。适用于方法总览、机制细节、teaser、任务可视化、实验对比与 scaling；不会强制所有研究采用相同流水线。

## 安装与使用

将 `skills/research-figures/` 整个目录复制到你的用户级 skills 目录，例如 `~/.codex/skills/research-figures/`。已有安装请先保留本地修改。入口是 [SKILL.md](skills/research-figures/SKILL.md)。

示例请求：

- `$research-figures 阅读这个项目的方法和实现，为核心贡献画 framework 和一张机制细节图，把所有图放进一个 PPTX。`
- `$research-figures 根据这些 CSV 画柱状对比、scaling 曲线和标准差范围，保持相同的颜色与字体。`
- `$research-figures 修改这份我编辑过的 draw.io，保留现有布局，把缺失的真实机器人图片留白并列出所需素材。`

Skill 本体只有文档。调用它的 agent 按当前任务编写绘图／导出代码；没有绑定本机路径的导出器。可选 [materials](materials/catalog.md) 与通用规则分开，可以单独保留或替换。

## 运行条件与交付

Agent 需要读取项目文件与参考图的能力。生成母稿需要可用的图像生成工具；原生交付需要 PPTX／draw.io 作者工具及相应实际渲染器。结果图默认使用 Matplotlib。缺少某项能力时应明确交付限制，不会把未生成的布局称为生成母稿，或把未经渲染的文件称为已验证。

默认架构图交付 PPTX、draw.io、SVG/PDF、PNG；结果图保留输入引用与最少重绘代码。字体默认 Comic Neue（数学使用匹配的数学字体），缺失时统一记录替代。字体文件不随仓库分发。

普通模块连线水平／垂直，跨行用正交折线。真实曲线、轨迹和空间几何保留实际坐标。PPTX 的复杂 freeform/group 模块移动后可能需要手动重排连线；两种编辑格式不自动同步。

## 验证与范围

[测试记录](docs/VALIDATION.md) 区分实际原生渲染、数值检查与仅阅读原图的结构推理。跨项目测试提供迁移证据，不保证任意新方法无需审查即可正确出图。每次调用仍需核对当前项目事实、实际导出与最终刊登尺寸。

本仓库不包含项目私有数据、训练结果或未经授权搬运的论文原图。素材来源、原始许可和使用范围见各素材目录；上游标识不代表对本项目的背书。
