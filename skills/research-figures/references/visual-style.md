# Visual direction and composition judgment

Read palette-and-type.md for exact colors/fonts and shape-vocabulary.md for geometry/ink recipes. This document owns overall composition and reference learning; it does not prescribe project science.

## Established direction

Dense, mature scientific sketch: natural moss/wheat/slate bodies with selective deep accents, black hand-directed contours, short handwritten technical labels, compact strong panel headings and meaningful internal visual mechanisms. White gutters and local contrast keep it readable. The desired density comes from states, tokens, masks, networks, geometry, real examples and measured panels, not from piles of text.

The layout is generated from the project's contribution and user request. An accepted earlier layout remains authoritative when the user only changes color or stroke character. Apply the resolved palette hierarchy within that layout rather than replacing it with uniform columns of cards. A deliberate heavy ink treatment should still communicate the reading order and causal relationships clearly.

A main framework can have a broad top execution lane and two compact lower detail/training panels. A control/behavior method can use an asymmetric preparation/interface/training mosaic. A multimodal method can use parallel expert lanes with a shared interaction band. These are composition options, not mandatory panels or imported model topologies.

## Information hierarchy

Make the core contribution immediately visible: its module, contrast or evidence occupies the most salient position or strongest filled region. Establish stage hierarchy with short headings and grouped scientific objects. Baseline preparation and infrastructure should be subordinate. Keep details with the mechanism they explain; do not put every definition into a legend.

Use a limited repeated motif vocabulary. Temporal samples should look like the same carrier across panels; a shared code should retain color/shape; actual versus reference traces should retain method encoding. Separate training and deployment visually where their available information differs. Feedback paths need dedicated corridors. Frozen and stopped-gradient boundaries need explicit labels.

Small diagrams inside modules should explain operations: support masks, token strips, state vectors, tensor relations, generic learned mappings or genuine observation sequences. Do not add scientific-looking patterns that have no project meaning. Tensor dimensions, frame clocks and model variants are facts to read, not design embellishments.

## Inspect requested references

When the user supplies papers/images or asks for new style research, read original figure pixels from the source paper HTML/PDF. Inspect the relevant teaser, framework, mechanism and result examples, not only captions or thumbnails. Keep exact source/version/figure attribution in a project-local study; keep author/institution/publication identities out of reusable defaults. A coauthor credit does not establish who drew a figure.

Observe typography hierarchy, panel topology, local density, colored area distribution, contour form, arrow corridors, repeated motifs, physical imagery and how plots are paired with qualitative evidence. Inspect actual figure-region fonts where possible; whole-PDF font listings also include body text and cannot establish the figure font alone.

Translate observations into anonymous reusable design rules. Separate visibly observed features from inferred font/author assumptions. A reference helps refine appearance and layout grammar; it must not decide a new project's modules, losses or claims. The existing style supplies appearance; [illustration-design.md](illustration-design.md) governs relevant-paper reading and adapting explanatory arrangements for new paper figures. Reuse applicable studies for later edits.

## Generate and reconstruct

Use generation-and-reconstruction.md. The master is the designed visual composition, not an illustration asset pasted behind a few editable labels. Read its regions and reconstruct their hierarchy, spacing, color weight, typography and visual rhythm. Correct generated scientific errors from the brief. Leave missing assets/data blank with an explicit handoff.

Match master-level composition before adding fine contour texture. Native files that merely contain matching colors and fonts but revert to a generic card grid do not reproduce the design. Use [native-style-reconstruction.md](native-style-reconstruction.md) to retain intentional shadows, dashes, hatching, depth and pen strokes. Only fine stochastic raster grain is routinely approximable; semantic modules, short labels and relationships remain native editable objects.

## Delivery judgment

View actual native renders beside the master at final size. Fix observed clipped headings, crossing labels, blank-looking oversized modules, weak contrast and font drift. Check the figure tells the intended contribution with minimal caption dependence. A diagram can be syntactically correct and visually unsuccessful; file validity is not an aesthetic conclusion.

Keep one project-local brief with resolved style choices, actual sources, missing inputs and export limitations. Preserve actual previews and editable artifacts. Avoid numeric aesthetic scoring, universal panel counts, repeated verification loops over settled facts and extra approval flows. Use judgment to choose useful detail.
