# Optional material catalog

The installed skill is independent of this directory. Use these sources only when the current figure needs them.

- [Verified official source index](ASSET-SOURCES.md): backend scenes/identities, robot hands/arms/humanoids, benchmarks and RGB-D/tactile sensors. Links and role/license notes; no copied paper plates.
- [Companion image bundle](https://github.com/GT-111/research-figures/releases/download/v0.1.0/research-figures-materials.zip): four genuine static views — Allegro V3 front/reverse three-quarter, Panda, G1 — with transparent RGBA and warm previews, original notices, camera/pose/source records. Private-repository access is required.

Extract the bundle separately from the skill, and supply its catalog path with a figure request. It can also live at the optional user-level `research-figures-materials/` directory beside `skills/`. Keep an existing material collection and its local edits intact when adding these files.

Static morphology is not execution evidence. Views are not displayed at a common physical scale. Actual task poses, contact or trajectories require the current project’s evidence. These images are rendered from licensed upstream geometry; they are not generative approximations of robot hardware. Generated artifacts are distributed as release attachments rather than tracked source.
