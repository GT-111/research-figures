## Reference, publication and caching

Reading an original figure to learn composition is different from reproducing its pixels. Keep paper figures as research references with source links. For publication, use the user's actual experiment frames or newly rendered licensed geometry, and cite/attribute third-party assets under their applicable terms. An upstream scene can appear as a clearly labeled upstream example; it must never imply downstream success or implementation. Source code licensing does not automatically license an external dataset, all meshes, a logo or a trademark.

Cache only selected originals in a separate optional material directory, with a small human-readable provenance file. Record source URL/revision, owner, license link or unresolved permission, model version, whether it is a logo/scene/morphology/example, and any crop/render modifications. Keep uncertain-rights media out of the public GitHub release; a verified link is enough. Do not package entire repositories or downloaded paper figures.

For newly rendered cutouts, store RGBA plus a warm-background preview. Record model, pose, camera, material and output size. Preserve real holes between links/fingers. Test the alpha against both a warm light field and ink-dark field. A static cutout claims morphology only. No renderer/physics installation is required merely to install the skill.

## Original reusable ingredients worth preparing

These can be authored independently as native editable groups, without third-party robotics media: empty timestamped frame strips; three-view image slots; token/feature carriers; a point-cloud inset with explicitly illustrative points; orthogonal local-axis glyphs; contact callout rings; an empty pose/joint chart; a tactile-frame slot; a scene-plus-project-name backing; aligned task-image/metric slots. Use the skill's resolved earth-ink type, shadow, hatch and contour recipes. Physical-looking pictures and numerical marks still come from actual evidence. An empty slot should name the missing item rather than substitute a fabricated result.
