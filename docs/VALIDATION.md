Repeatable new-project prompt:

> Draw a compact editable mechanism for a proposed mobile-robot mapping method: RGB-D and measured camera pose update a persistent scene map; a text query reads the map to retrieve candidate objects; a geometric planner consumes candidates and a free-space map to produce a path. Pose is measured. Updates occur per frame; querying occurs only when requested. No empirical results or photos available. Deliver one PPTX, draw.io and actual previews.

Tests must distinguish conceptual routing from measured geometry; source examples from project evidence; unavailable inputs from zeros; and editable objects from live connector attachment. Actual rendered output matters more than XML validity. Generated evaluation artifacts remain outside tracked source and can be attached separately to a release.

## Release outcome

The independent proposed-mapping trial completed a generated master, native PPTX/draw.io, actual LibreOffice/draw.io previews and edit copies. The first PPTX render reversed the persistent-state return and disconnected the map-read route because custom connector geometry was reinterpreted. Standard native bent-connector presets repaired all 11 relations; the corrected final previews were inspected. This failure informed the architecture guidance on testing actual return orientation.

Layout and master development used only the brief and skill; exporter repair subsequently received a pointer to prior native-connector mechanics. The agent correctly retained measured pose as an input and separated per-frame map update from on-request retrieval/planning. No learned pose estimator or measured outcome was added. Component movement and text edits preserved module styling. These were file edits followed by native renders, not interactive application drag tests. PPTX connectors require manual rerouting; draw.io endpoints follow attached bodies, but fixed waypoints may need adjustment to restore alignment after movement. Native contour treatment is cleaner than the master and paper grain is omitted.
